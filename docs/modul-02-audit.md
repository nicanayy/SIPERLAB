# Audit Modul 2 - Semantic HTML dan Formulir

## Sebelum perbaikan

- Struktur halaman masih sederhana.
- Katalog peralatan belum menggunakan struktur semantic HTML yang lengkap.
- Formulir peminjaman belum tersedia.

## Setelah perbaikan

- Landmark halaman sudah menggunakan header, nav, main, dan footer.
- Hierarki heading sudah dibuat secara logis.
- Katalog memiliki minimal tiga item peralatan.
- Setiap item menggunakan article, figure, img, dan figcaption.
- Formulir peminjaman menggunakan fieldset dan legend.
- Setiap input memiliki label.
- Field penting memiliki atribut name.
- Validasi HTML diterapkan pada NIM, durasi, keperluan, dan checkbox persetujuan.
- Urutan Tab pada halaman sudah logis.
- Halaman sudah divalidasi menggunakan Nu HTML Checker.

## Checklist

- [x] Landmark halaman masuk akal.
- [x] Hierarki heading logis.
- [x] Minimal tiga item katalog lengkap.
- [x] Label dapat diklik dan fokus berpindah.
- [x] Field penting memiliki name.
- [x] Submit kosong memunculkan validasi browser.
- [x] Urutan Tab logis.
- [x] Validator tidak menampilkan error utama.
